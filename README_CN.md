# **nano11 极致精简构建器 (GUI 交互版) 🔬**

基于 NTDEV 的 nano11 项目，通过 PowerShell 自动化构建超轻量级 Windows 11 镜像。

## **☢️ 极其重要：操作前必读**

这是一个 **高度实验性** 的脚本，旨在创建极小化的开发测试环境。
* **不可维护性：** 生成的系统移除了 **Windows 组件库 (WinSxS)**、**Windows Update** 和 **Windows Defender**。
* **无法还原：** 您将无法添加新功能、语言包、驱动程序，也无法接收任何安全更新。
* **移除内容：** 包括绝大部分 bloatware 应用、搜索、BitLocker、生物识别以及除 VGA、网络、存储之外的大多数驱动程序。
* **用途：** 仅推荐用于虚拟机、嵌入式测试或极速开发环境。

## **🖥️ GUI 工具使用说明**

为了让精简过程更加直观，我们新增了图形用户界面 (GUI)，让您无需修改脚本代码即可自定义精简方案。

### **1. 准备工作**
1. **下载 ISO：** 从微软官网获取 Windows 11 ISO 镜像。
2. **挂载镜像：** 右键点击 ISO 文件，选择“装载”，并记下该虚拟光驱的**盘符**（例如 `E:`）。
3. **环境权限：** 以管理员身份打开 PowerShell，运行以下命令允许脚本执行：
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process

```

## **2. 界面操作步骤**

1. **输入盘符：** 在界面顶部的文本框输入您挂载 ISO 的盘符字母（只需字母，无需冒号）。
2. **分卷索引：** 输入您想要处理的 Windows 版本索引（如专业版通常为 1 或 6）。
3. **勾选精简项：**
* **移除内置 App：** 删除 Xbox、照片、摄像头等预装软件。
* **移除 Defender：** 彻底禁用并移除安全中心。
* **极致 WinSxS 清理：** 大幅缩小体积，但会导致系统彻底无法更新。
* **绕过硬件限制：** 自动注入补丁，使镜像支持在非 TPM 2.0/旧 CPU 的设备上安装。


4. **一键构建：** 点击“开始构建”，脚本将自动完成挂载、精简、压缩及生成新 ISO 的全过程。

---

## **🛠️ 核心功能列表**

* **自动化部署：** 内置 `autounattend.xml` 自动跳过微软账户登录、接受 EULA 并启用本地管理员账户。
* **极致压缩：** 最终镜像会导出为高度压缩的 `.esd` 格式，比标准镜像缩小约 3 倍。
* **原生工具：** 仅依赖系统内置的 DISM 命令及官方 `oscdimg.exe` 工具。
* **性能优化：** 预设了禁用遥测、禁用 Copilot、禁用赞助商广告等大量注册表优化。
